This is the build guide for custom build

run `npm run build` to build the project (or run the component commands if failed)

The output files are not well placed in a folder and shattering in the project root folder.
Please grab the files and manually put into a single folder
Here list the necessary files: (referring to the file structure with npm version)

```
/locale
/scss
index.css
index.esm.js
index.js
index.js.map
index.min.js
index.min.js.map
```
